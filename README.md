> 🚀 Логирование времени в Kaiten прямо из IntelliJ IDEA

Плагин для IntelliJ IDEA, который позволяет быстро логировать время в Kaiten после выполнения коммита или по команде. Автоматически определяет ID карточки из названия ветки, загружает доступные роли, показывает уже залогированное время по карточке.

## 📋 Особенности

- ✅ **Автоматическое определение карточки** из названия ветки (поддерживает форматы: `feat/DEV-12345`, `DEV-12345`, `bugfix/DEV-12345_description` и др.)
- ✅ **Просмотр уже залогированного времени** по карточке (сгруппировано по датам)
- ✅ **Выбор роли** из списка, загруженного из API Kaiten (с запоминанием последней выбранной)
- ✅ **Информация о текущем пользователе** (имя, email, роль, часовой пояс)
- ✅ **Статистика времени за сегодня** (общее время и разбивка по карточкам)
- ✅ **Автоматическое открытие** после коммита (опционально)
- ✅ **Сохранение настроек** (токен, базовый URL, последняя роль, опции автооткрытия)
- ✅ **Поддержка времени** в минутах и часах
- ✅ **Работает в любом проекте** с Git

## 🚀 Установка

### Из маркетплейса (скоро)
1. Откройте IntelliJ IDEA → **Settings** → **Plugins**
2. Найдите `Kaiten Time Logger`
3. Нажмите **Install**

### Из ZIP-файла
1. Скачайте последний релиз с [GitHub Releases](https://github.com/Depik400/kaiten-intellij-plugin/releases)
2. В IDEA: **Settings** → **Plugins** → ⚙️ → **Install Plugin from Disk...**
3. Выберите скачанный ZIP-файл и перезапустите IDE

### Из исходников
```bash
git clone https://github.com/Depik400/kaiten-intellij-plugin.git
cd kaiten-intellij-plugin
./gradlew buildPlugin
# Плагин появится в build/distributions/*.zip
```

## 🎯 Использование

### Первоначальная настройка

1. Откройте **File** → **Settings** → **Tools** → **Kaiten Time Logger**
2. Укажите:
    - **Базовый URL** вашего пространства Kaiten (например, `https://ваш-пространство.kaiten.ru`)
    - **API токен** (инструкция ниже)
3. Настройте дополнительные опции:
    - Автоматически открывать окно после коммита
    - Автоматически определять карточку из ветки

### Команды

| Действие | Способ вызова |
|----------|---------------|
| Открыть окно логирования | `Ctrl+Alt+L` (или `Cmd+Alt+L` на macOS) |
| Показать информацию о пользователе | Через поиск действий (`Ctrl+Shift+A` → `Kaiten: Показать информацию о пользователе`) |
| Показать время за сегодня | Через поиск действий |
| Обновить список ролей | Через поиск действий |
| Сбросить настройки | Через поиск действий |

### Модальное окно

При вызове команды открывается окно:

- **ID карточки** — автоматически подставляется из ветки (если опция включена)
- **Затраченное время** — можно выбрать минуты или часы
- **Дата выполнения** — по умолчанию сегодня
- **Роль** — выпадающий список, загруженный из Kaiten
- **Комментарий** — описание выполненной работы

После отправки вы увидите уведомление об успехе или ошибке.

### Просмотр уже залогированного времени

Когда вы вводите или выбираете ID карточки, плагин автоматически загружает и отображает:

- Общее время по карточке
- Разбивку по датам с комментариями

## ⚙️ Настройки

Все настройки сохраняются на уровне IDE и не зависят от проекта.

| Параметр | Описание |
|----------|----------|
| Базовый URL | Адрес вашего Kaiten (например, `https://company.kaiten.ru`) |
| API Token | Токен доступа к API Kaiten |
| Автоматически открывать после коммита | После успешного коммита автоматически показывать окно логирования |
| Автоматически определять ID карточки из ветки | Пытаться извлечь номер карточки из имени текущей ветки Git |

## 🔑 Как получить API токен Kaiten

1. Зайдите в ваш Kaiten
2. Перейдите в **Настройки** (Settings) → **API Токены** (API Tokens)
3. Создайте новый токен с правами:
    - Чтение информации о пользователе
    - Создание временных логов
    - Чтение ролей
4. Скопируйте полученный токен и вставьте в настройки плагина

## 🌿 Поддерживаемые форматы веток

Плагин умеет извлекать ID карточки из следующих форматов:

- `feat/DEV-12345`
- `DEV-12345`
- `bugfix/DEV-12345_description`
- `feature/TASK-123`
- `release/DEV-123`
- `hotfix/DEV-123`
- Любые другие, содержащие число (как запасной вариант)

## ❓ Часто задаваемые вопросы

**Почему не загружаются роли?**
- Проверьте, что в настройках указан корректный API токен и базовый URL.
- Убедитесь, что ваш пользователь имеет доступ к API (обычно даётся через токен).

**Не появляется окно после коммита**
- Убедитесь, что в настройках включена опция «Автоматически открывать после коммита».
- Плагин открывает окно только после успешного коммита (не после отмены).

**ID карточки не определяется**
- Проверьте, включена ли опция автоопределения.
- Убедитесь, что ваша ветка соответствует одному из поддерживаемых форматов.
- Если ветка содержит просто число, оно тоже будет извлечено (например `fix-12345`).

**Ошибка "Access is allowed from Event Dispatch Thread only"**
- Пожалуйста, обновите плагин до последней версии — эта проблема исправлена.
